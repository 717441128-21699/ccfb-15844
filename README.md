# 膜色流光 · WebGPU 肥皂泡互动展项

科技馆大屏互动展项：基于**真实膜厚物理**与**薄膜干涉光学**的肥皂泡仿真。
泡泡表面每个点有独立膜厚，重力排液使顶部变薄、表面张力不均产生漩涡流动，
颜色由光在膜上下两面反射的干涉实时计算，膜薄到几十纳米形成黑膜、黑膜扩大即破裂。
观众可用手势或指针**吹泡、戳泡、吹气**。

## 物理模型

润滑理论（lubrication theory）有限体积求解，球面等距经纬网格：

```
∂h/∂t = -∇·q - E
q = ρg sinθ·h³/(3μ)·eθ  +  h²/(2μ)·∇σ        （重力排液 + Marangoni 流）
σ(Γ) = σ₀ + E_s(0.5 - Γ)
```

- **重力排液**：顶部膜厚满足 Frankel-Mysels 律 `h(t)=h₀/√(1+t/τ)`，
  特征时间 `τ=3μ/(ρgh₀)`，单元测试以单格盒子解析 ODE 逐式验证通量公式。
- **漩涡流动**：表面张力经向梯度经斜压项注入涡量 `ω`，半拉格朗日平流 + 扩散，
  再由流函数 `∇²ψ=-ω` 的雅可比迭代恢复无散旋涡速度。
- **黑膜与破裂**：膜厚降到 ~8–12nm 时光学相消显黑，黑膜面积占比超阈值（配方参数）即破裂。
- 南极设 Plateau 边界储液槽，极区 `sinθ` 钳制 + 相对变化自适应子步保证数值稳定。

## 光学模型

- 对称膜（空气-膜-空气）多光束反射，s/p 偏振分别用菲涅耳系数叠加，自然光取平均；
  两界面反射相移相同而抵消，故 `h→0` 反射相消 → 黑膜。
- 全光谱 380–780nm（41 波长）× D65 × CIE 1931 配色函数积分到 XYZ 再转线性 sRGB，
  厚度扫描自然复现**牛顿色序**（黑→银灰→黄→红→紫蓝→青绿→循环）。
- 入射角改变 `cosθ₂` 与菲涅耳振幅，同一厚度换角度颜色自动变化。
- 结果预计算为 `256×64` 干涉 LUT（膜厚 × 入射角），渲染时一次纹理查找。

## WebGPU 实现

- 每个泡泡 4 张 RGBA32F 纹理（h/Γ/ω/ψ），3 个计算 pass：
  平流注入 → Jacobi 流函数（10 次迭代）→ 膜厚更新，每帧 8 个稳定子步。
- 干涉 LUT 由计算着色器全光谱积分生成（rgba16float，可过滤）。
- 渲染用全屏三角形 + 片元级光线-球面求交，无顶点缓冲，最多 6 实例。
- WGSL 数学与 `src/physics/reference.ts`、`src/optics/interference.ts` 逐式对应，
  TypeScript 参考实现由单元测试锁定，作为 GPU 端的对照基准。

### 性能

6 泡 × 8 子步 × 12 次分发 = 每帧 576 次轻量计算分发，网格 32×48=1536 单元。
SwiftShader 软件渲染实测 6 泡 >80fps；独显硬件 4K@60fps 余量充足。

## 四种肥皂液配方（参数为公开实验文献取值区间整理）

基础餐洗 / 甘油长寿 / 糖浆大泡 / 专业展项（瓜尔胶），黏度、表面张力、弹性、
折射率（Cauchy 色散）、蒸发率、黑膜厚度、破裂阈值各不同，在参数页可切换。

## 开发

```bash
npm install          # 安装依赖并自动复制 MediaPipe WASM 到 public/
npm run fetch:model  # 下载手势模型（公网，一次即可）
npm run dev          # 开发服务器
npm test             # 物理/光学单元测试（18 项）
npm run test:e2e     # WebGPU 端到端测试（需本机 Chrome，8 项）
npm run build        # 类型检查 + 生产构建
```

需要 Chrome/Edge 113+ 并开启硬件加速。手势模型与 WASM 均在 `public/mediapipe`，
展项可完全离线运行。桌面无摄像头时用指针：左键戳泡、Shift+左键吹泡、右键吹气。
